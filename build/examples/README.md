# Custom Program Examples

This folder contains example programs with display images.
Users can customize both the images and the code.

## How to customize:
1. Replace any `.png` image with your own (keep the same filename)
2. Edit the `.json` file to change program name, description, or code
3. Recommended image size: 200x150px (PNG format)
