📊 Dashboard — Global Metrics /dashboard

Cards: Total Institutions (tenants.length), Active Students (SUM user_count), System Health (active / total). Source: GET /api/admin/tenants. Click cards to jump to /tenants or /users.

Tip: If Active < 90%, check Tenants → Status filter. All Super Admin only.

👥 Users — User Directory /users

Search by name/email, filter by role (Super Admin, Tenant Admin…). Create: POST /api/admin/users with tenant_id. Detail at /users/:id via PATCH /admin/users/:id. Super Admin sees all; Tenant Admin scoped.

🔐 Roles — Role Manager /roles

Default: Super Admin, Tenant Admin, Lead Instructor, Lab Tech, Guest Lecturer, Student. Permissions in roles.permissions JSONB. Guards: isSuperAdmin / isAdmin. PATCH /api/admin/roles/:id (Super Admin only).

Help: /docs/ROLES.md

📝 Audit — System Logs /audit

Table audit_log: TENANT_CREATED, WHITE_LABEL_ONBOARDED, TENANT_BRANDING_UPDATED via writeAudit(). Filter by tenant, action, date. /docs/AUDIT.md

🎨 White-Label — Single Wizard /white-label /design → /white-label

Why one? Previously two routes (/white-label Setup + /design White-Labeling) were identical. Now single page at /white-label; /design redirects to /white-label?tenantId=X (preserves query). Sidebar shows only one White-Label entry with palette icon.

Step 1 Domain: oakwood.{host} (instant) vs lab.school.edu → {cnameTarget} (1 CNAME). Check GET /tenant/check-availability.
Step 2 Branding: logo 2MB → POST /admin/tenants/:id/logo, colors, preset swatches, WCAG, loginHeadline/supportText, app name.
Step 3 Verify & Go Live: GET /tenant/verify-domain → dns.resolveCname() vs PLATFORM_HOST.

Super Admin picker at top → ?tenantId= → GET /admin/tenants/:id → save via PATCH /admin/tenants/:id (same columns as Tenants). Tenant Admin uses POST /tenant/white-label/setup. All synced with /tenants table.
