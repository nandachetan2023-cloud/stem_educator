# The STEM Educator - Program Examples

Example programs for students to learn hardware programming with blocks and Python.

## Categories

### 🟢 Beginner
- LED Blink
- LED ON/OFF with Button
- Traffic Light
- Buzzer Melody

### 🔵 Intermediate
- Servo Motor Control
- Ultrasonic Distance Sensor
- Temperature Monitor
- LED Fade (PWM)
- Light Sensor (LDR)

### 🟣 Advanced
- Smart Street Light
- Obstacle Avoiding Robot
- Weather Station
- WiFi Controlled LED (ESP32)
- Bluetooth Remote Control (ESP32)

## How to Use
1. Open The STEM Educator editor
2. Click **Connect** and select your board (Arduino Uno, Nano, Mega, or ESP32)
3. Connect via **USB** or **Bluetooth**
4. Load an example from the **Python** tab or recreate it using **Blocks**
5. Click **Run** to execute!
