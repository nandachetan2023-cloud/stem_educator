⚡ Hardware Blocks

TurboWarp-based Arduino & ESP32 Programming Platform

Backend Status Launch Dashboard Documentation

🎯 Supported Boards

  • Uno Arduino Uno (ATmega328P)
  • Nano Arduino Nano (ATmega328P)
  • Mega Arduino Mega 2560
  • ESP32 ESP32 (WiFi + BLE)
  • CAM ESP32-CAM (optional)

🔌 Connectivity

  • USB Web Serial API
  • WiFi WebSocket for ESP32
  • BLE Bluetooth LE for ESP32
  • Auto Auto-detect + Reconnect
  • Multi Multi-device support

📦 50+ Scratch Blocks

  • 🔗 Connection blocks
  • 💡 Digital / Analog I/O
  • 🔄 PWM + Servo control
  • 📡 Sensors (Ultrasonic, Temp/Humidity)
  • 🖥 OLED/LCD Display
  • ✨ NeoPixel LED strips
  • 📬 I2C / SPI Communication
  • 📶 ESP32 WiFi + BLE
